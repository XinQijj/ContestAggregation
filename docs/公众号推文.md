# 竞赛速递上线｜一个网页查清 94 项校级认定竞赛

> 复旦大学智能机器人与先进制造创新学院

想打比赛，却不知道有哪些、什么时候报名、往届怎么做？我们整理了一个**竞赛信息网站**，打开就能查。

🔗 **网址**：https://xinqijj.github.io/ContestAggregation/
（建议电脑打开；手机也可以浏览）

---

## 一、能查到什么

**1. 94 项校级认定竞赛**
按《复旦大学高水平学科竞赛目录（2026 年 7 月更新）》整理，含一类 32 项、二类 62 项。其中 25 项与本院专业（机器人、AI、编程、工科）关系较近，已经标出。

**2. 两种查看方式**
- **按加分等级**：一类、二类分开列出，勾选“只看机器人学院相关”可以只看和本院专业有关的比赛
- **按报名时间**：**现在正在报名**的比赛放在最前，其余按离开放报名还有几个月排序，不容易错过报名

**3. 点开比赛能看到**
- 官网链接
- 一键搜索 B 站、知乎、YouTube、GitHub、CSDN 上的经验帖和往届方案
- 自动收录的 GitHub 开源项目，按 Star 排序，可以参考往届代码

**4. 黑客松**
网页底部列出大公司和知名黑客松，另有 Devpost 上**正在报名**的线上黑客松。

## 二、数据来源

| 内容 | 来源 | 更新方式 |
|---|---|---|
| 竞赛名单、一类 / 二类分级、推荐院系 | 《复旦大学高水平学科竞赛目录（2026 年 7 月更新）》 | 学校目录更新时同步修改 |

页面顶部显示数据最后一次更新的时间。

## 三、使用须知（请务必阅读）

1. **一类 / 二类 ≠ 本院保研加分。** 一类 / 二类是学校竞赛目录的分级。部分一类竞赛和本院专业关系不大，**能不能算进推免加分，以学院当年发布的推免细则为准**，有疑问请咨询学院老师。
2. **报名时间仅供参考。** 报名时间是按往年整理的大致月份，每年可能会变，**请以赛事官网和学院通知为准**。
3. **开源方案只供学习参考。** 请遵守各比赛的规则和学术诚信要求，不要直接照搬代码或方案。
4. **发现信息有误或想加比赛**，欢迎在后台留言或联系我们，我们会尽快修改。
